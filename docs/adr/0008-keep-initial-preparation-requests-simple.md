# Keep initial preparation requests aligned with group schedules

The legacy SISLAB workflow lets professors submit requests on their group's recurring weekday and lets staff print them without a review or fulfillment step. The first release keeps submitted requests read-only and blocks schedule or team-count changes and deactivation for groups with future, non-voided requests; it does not add one-time schedule exceptions or academic-period date validation. This avoids silently changing preparation details and avoids new administrative work while the lab adopts the request feature.
